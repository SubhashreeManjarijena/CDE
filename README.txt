Digital MV Customer Service Management System - front-end prototype
Alfanar Electrical Systems (demo) - single self-contained file, no install, no server.

HOW TO RUN
1. Unzip this folder.
2. Double-click index.html (Chrome, Edge or Firefox). It works offline.
   (Fonts load from Google Fonts when online; the app works without them.)

NOTES
- All data is kept in memory only. Refreshing the page resets everything
  (the top-right user menu also has "Reset demo data").
- Nothing is sent to any server. To hand data over, use the download buttons
  (CSV, PDF, KML, receipt) in Reports, Dashboard exports and each case.
